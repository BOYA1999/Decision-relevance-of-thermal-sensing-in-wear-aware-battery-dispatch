# Wear-aware thermal dispatch code package

This repository contains the executable model, public input data, recorded interval-level outputs, and replay checks for a stylized battery-dispatch computation. The thermal state, observation map, tariff, battery parameters, and wear laws are explicit model assumptions; the package does not contain measured thermal images, switching waveforms, field logs, or device-health labels.

The repository is deliberately code/data-only. It excludes the manuscript, supplementary text, figures, references, title page, cover letter, author information, reviewer correspondence, submission files, private workspace paths, and contact metadata.

## Layout

- `*.py`, `config.json`, `plant_parameters.json`: model, observer, MPC, replay, and check code.
- `data/`: the public hourly driver and derived quality-filtered tables.
- `runs/`: recorded `intervals.csv`, `metrics.json`, and `solver_checks.json` files. Full-resolution `.npz` traces are omitted and can be regenerated by replay.
- `results/`: machine-readable aggregate outputs and integrity reports.
- `vendor/` and `licenses/`: third-party code and license notices.

## Environment

The recorded environment used Python 3.12.0. Install the pinned dependencies with:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The supplied tables and run records support offline replay. A network connection is only needed if `prepare_public_data.py` is used to refresh the public OPSD source files.

## Checks and replay

From the repository root:

```powershell
.\.venv\Scripts\python.exe plant_checks.py
.\.venv\Scripts\python.exe observer_checks.py
.\.venv\Scripts\python.exe rainflow_convex.py
.\.venv\Scripts\python.exe mpc_checks.py
.\.venv\Scripts\python.exe replay_physics.py runs/main/2017-07-01_heatwave_dr_full_41 --report replay_report.json
```

Replay validates the recorded actions against the bundled synthetic plant and wear ledger. It does not re-solve the optimizer or turn a numerical gate into a pass. To regenerate omitted traces for a disposable copy, add `--write-traces`; generated `.npz` files are ignored by Git.
